# sprint4_segundo_intento
Web cocktails creation

Esta web necesita registrarse para poder funcionar. Consiste en una web en la cual puedes registrar tus ingredientes necesarios para crear tus cocktails favoritos.

* Tecnologias Usadas:
    - Laravel 12 (Framework backend).
    - MySQL (Base de datos relacional).
    - Tailwind (estilos).
    - Laravel Brezze (Login).

* Requisitos previos:
    - PHP 8.1 o superior.
    - Composer.
    - Node.js y npm.
    - MySQL.

* Bases de datos:
    - Cocktails.
    - Ingredients.
    - Cocktail_ingredient.
